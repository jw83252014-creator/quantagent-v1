### Source inspiration

### Core conceptual chain

1. Gödel: some truths are true but not provable inside the same system.
2. Wolfram: computation/reality can be irreducible; sometimes the only way to know is to run the system.
3. Prediction markets: prices are crowd-computed probabilities about future truth.
4. Trading bot: a bot seeks places where the market's probability diverges from better research/computation.
5. Profitability becomes a reward signal for truth-seeking, if and only if the edge is real and risk is controlled.

### Bot architecture proposed by Grok

- Start small: ~$40 bankroll.
- Phase 1: arbitrage scanner / thin-market opportunities.
- Phase 2: LLM forecaster / auto research.
- Phase 3: market maker once capital is larger.
- Auto-switch modes based on signals:
  - too many traders
  - volume/crowding
  - 7-day P&L
  - bankroll size
  - edge degradation
- Suggested sources:

## Product Interpretation

### TradeApp / QuantAgent version

A **TruthBot** is not just a trading bot. It is a research-to-probability engine.

Input:

- market question
- market price
- current order book
- news
- X signal
- historical outcomes
- quantitative computation
- human/agent review

Output:

- fair probability estimate
- market-implied probability
- edge estimate
- confidence
- risk flags
- paper-trade decision
- later: gated trade recommendation

### Everything Cockpit version

The same architecture applies outside trading:

```text
claim → evidence → computation/research → confidence → action recommendation
```

This means the TruthBot is one instance of the larger Everything Cockpit.

### Photo Memory version

Photos/screenshots/documents are evidence nodes.

For BidLocal / disputes / field work:

- A photo with timestamp/GPS/EXIF/OCR can prove when/where work happened.
- It can attach to a job card, bid, dispute, or invoice.
- It becomes searchable memory instead of a dead camera roll.

For personal memory:

- Ask: “show me the photo from the day Cordell had his birthday and Wolfram posted Gödel.”
- System retrieves matching images, chats, posts, notes, and creates a 15-second memory clip or visual summary.
