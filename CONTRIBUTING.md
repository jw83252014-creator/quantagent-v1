# Contributing to QuantAgent-v1

## Workflow

1. Create a branch.
2. Keep changes small and reviewable.
3. Mark artifacts clearly: `RESEARCH`, `SIMULATED`, or `LIVE`.
4. Never add credentials.
5. Open a PR for review.

## Agent roles

- Null: security/risk/memory/documentation gate
- Claude/Claire: prompt engineering, review, implementation support
- Grok: architecture/source-thread synthesis
- Jeff: final business/risk approval
